## 1. Executive Overview & Problem Statement Context

### The Core Problem (PS26189 — MHA / NCRB)
Organized crime syndicates across India operate in a decentralized, compartmentalized manner. A single criminal hierarchy may be orchestrating **Narcotics Smuggling** in Maharashtra, **Hawala Laundering** in Gujarat, **Human Trafficking** in West Bengal, and **Arms Procurement** across border states.

Investigators are bottlenecked by:
1. **Unstructured Data Overload**: Critical intelligence resides in raw narrative text (FIRs, daily case diaries, surveillance logs, telephonic CDR transcripts, and seizure panchnamas).
2. **Deliberate Obfuscation**: Operatives utilize aliases (*"Sethji"*, *"Bhai"*, *"Doctor"*), burner SIM fleets, shell logistics companies, and multi-tier mule accounts.
3. **Cross-Domain Blindspots**: Police stations operate in regional silos; a suspect flagged for land fraud in one district is rarely correlated with an ongoing extortion case in another.
4. **Judicial Admissibility Hurdles**: Converting AI insights into court-admissible evidence compliant with **Section 65B of the Indian Evidence Act (Bharatiya Sakshya Adhiniyam 2023)** requires strict cryptographic chain of custody.

**NexusTrace** was engineered as an end-to-end AI platform delivering zero-loss information extraction, cross-domain link analysis, explainable reasoning, and automated court dossier generation.

### 2.2 Infinite Canvas & Visual Link-Analysis Engine (`Board.jsx`, `PinNode.jsx`)
* **Coordinate Math**: Panning offset $(x, y)$ and zoom scale ($s \in [0.25, 2.5]$) are maintained in state. During dragging, the world coordinate delta is computed as:
  $$\Delta X_{\text{world}} = \frac{\Delta X_{\text{screen}}}{s}, \quad \Delta Y_{\text{world}} = \frac{\Delta Y_{\text{screen}}}{s}$$
  This prevents node drift and desynchronization regardless of canvas magnification.
* **Dynamic Link-Wire Severance (Search Isolation)**: When searching for an entity (*e.g., "Farhan"*), `visibleEntities` isolates the matched node and its immediate neighbors. The SVG path generator enforces strict dual-endpoint existence:
  ```javascript
  if (!visibleMap[srcId] || !visibleMap[tgtId]) return null;
  ```
  This eliminates phantom spiderweb lines shooting to `(0, 0)`.
* **Hardware-Accelerated SVG Rendering**: Connections are drawn with curved cubic Bézier paths (`d="M x1 y1 C cx1 y1, cx2 y2, x2 y2"`) with directional markers and confidence styling.

### 3.3 Security, JWT Authentication & RBAC Engine (`auth.py`)

  1. `INVESTIGATOR` (`investigator_01` / `Investigate#2026`): Submits feedback, views graphs, generates dossiers.
  2. `OFFICER_IN_CHARGE` (`ncrb_admin` / `Admin#MHA2026`): Full admin privileges, triggers pipeline runs, modifies cases.
  3. `AUDITOR` (`judicial_auditor` / `Audit#Secure2026`): Inspects immutable audit logs and validates Section 65B certificates; forbidden from submitting feedback.

### 3.4 Service Layer Deep Dive

#### `GraphService` (`backend/services/graph_service.py`)
* Manages graph retrieval from SQLite and structured cache.
* Builds dynamic NetworkX graphs applying exponential time-decay weights:
  $$w(t) = w_0 \cdot \exp\left(-\frac{\ln(2)}{180} \cdot \Delta t\right)$$
* Applies Officer Verification Multipliers (Confirmed edges: $\times 1.25$, Rejected edges: $\times 0.05$).
* Calculates multi-hop shortest paths with Floyd-Warshall / Dijkstra weighted routing.

#### `DossierService` (`backend/services/dossier_service.py`)
* Compiles official court briefs using **ReportLab PlatyPus**.
* Generates a **Section 65B Electronic Certificate of Authenticity**.
* Embeds deterministic SHA-256 evidence hashes, printing officer credentials, timestamp, and device metadata.

## 4. SECTION 3: PIPELINE ARCHITECTURE & EVALUATION

The pipeline is organized in `pipeline/` as a linear, stage-gated system converting raw text into a 10-node POLE knowledge graph.

### 4.1 Stage-by-Stage Architecture

```
Stage 1: Data Ingestion (pipeline/data_ingestion/loader.py)
  └── DatasetLoader parses 148 documents across 10 domains.
Stage 2: Preprocessing & PII Redaction (pipeline/preprocessing/)
  ├── TextPreprocessor applies NFKC normalization and whitespace collapsing.
  └── SensitiveIdRedactor masks Aadhaar, PAN, Passport, Accounts, Phones.
Stage 3: 10-Node POLE NER (pipeline/ner/)
  └── HybridNERModel extracts all 10 entity node types.
Stage 4: High-Recall Relation Extraction (pipeline/relation_extraction/)
  └── RuleBasedRelationExtractor parses passive voice, Hawala, and multi-sentence rules.
Stage 5: Cross-Document Entity Resolution (pipeline/entity_resolution/)
  └── RuleBasedEntityResolver merges aliases to canonical kingpin IDs.
Stage 6: Knowledge Graph Construction (pipeline/knowledge_graph/)
  └── KnowledgeGraphBuilder builds KGNode/KGEdge with ISO 8601 timestamps.
Stage 7: Graph & Temporal Analytics (pipeline/graph_analytics/)
  └── InvestigationAnalyticsEngine computes Hub scores, time-decay weights, and event sequences.
```

---

### 4.2 The 10-Node POLE Schema Mapping

NexusTrace supports the mandated **10-Node POLE Schema**:
1. `PERSON` (Suspects, operatives, handlers, witnesses, kingpins)
2. `ORGANIZATION` (Front companies, shell corporations, cartels)
3. `LOCATION` (Safehouses, warehouses, ports, drop points)
4. `VEHICLE` (Getaway cars, trucks, registration numbers)
5. `PHONE_NUMBER` (Intercepted MSISDNs, burner SIM fleets)
6. `BANK_ACCOUNT` / `FINANCIAL_ACCOUNT` (Mule accounts, IBANs)
7. `TRANSACTION` (Financial transfers: `HAWALA`, `NEFT`, `CASH`, `CRYPTO`)
8. `CASE` (FIR and court incident cases, sections applied)
9. `EVENT` (Meetings, intercepts, raids, drops, pickups)
10. `DOCUMENT` (FIR text, surveillance logs, CDR records, seizure memos)

---

### 4.3 P0 Sensitive ID Redaction Engine (`SensitiveIdRedactor`)
Sanitizes raw documents before graph storage in compliance with the **DPDP Act 2023** and **Indian IT Act Section 43A**:
* **Aadhaar UID** (`12 digits`): `\b\d{4}\s\d{4}\s\d{4}\b` $\rightarrow$ `[ID Redacted: XXXX-XXXX-1234]`
* **PAN Card** (`10 alphanumeric`): `\b[A-Z]{5}[0-9]{4}[A-Z]\b` $\rightarrow$ `[PAN Redacted: XXXXX1234X]`
* **Passport Number**: `\b[A-Z][0-9]{7}\b` $\rightarrow$ `[Passport Redacted: X*****7]`
* **Bank Account Number** (`9-18 digits`): `\b\d{9,18}\b` $\rightarrow$ `[Account Redacted: XXXX-XXXX-1234]`
* **Phone Numbers**: `\b\+?91[\s-]?[6-9]\d{9}\b` $\rightarrow$ `[Phone Masked: +91-XXXXX-98765]`

---

### 4.4 High-Recall Relation Extraction Engine (`>80% Recall`)
* **Passive Voice Handling**: Correctly inverts source/target on passive triggers (`"was instructed by"`, `"received consignment from"`, `"was financed by"`).
* **Hawala & Financial Layering**: Extracts complex Hawala routing (`"settled hisaab via hawala"`, `"transferred ₹X to mule account"`).
* **Cross-Sentence Evidence**: Connects entities across adjacent sentences within paragraphs.

### 4.5 Graph Analytics & Temporal Intelligence

#### Ensemble Master Hub Score Formula
$$\text{Hub}(v) = 0.35 \cdot C_D(v) + 0.35 \cdot C_B(v) + 0.15 \cdot C_C(v) + 0.15 \cdot PR(v)$$

#### Time-Decay Edge Weighting Formula
$$w(t) = w_0 \cdot \exp\left(-\frac{\ln(2)}{T_{\text{half}}} \cdot \Delta t\right), \quad T_{\text{half}} = 180\text{ days}$$

#### Chronological Event Sequencing
`get_chronological_events()` extracts and sorts all interactions, calls, and drops chronologically for sequence reconstruction.

### 6.1 Enterprise Infrastructure & Scalability
1. **PostgreSQL + pgvector Migration**: Migrate relational models to PostgreSQL 16 with `pgvector` extension to enable semantic vector similarity search alongside relational queries.
2. **Celery + Redis Distributed Task Queue**: Offload document ingestion and graph re-clustering to asynchronous distributed background workers.
3. **Neo4j Enterprise Graph Sharding**: Deploy Neo4j Fabric for cross-state multi-tenant graph partitioning.

### 6.2 Advanced AI/ML & Deep Learning Enhancements
1. **Fine-Tuned Domain IndicBERT / Llama-3-8B**: Deploy a quantized on-premises LLM fine-tuned on legal IPC/BNS crime narratives for open-domain relation extraction.
2. **Graph Neural Networks (GNN / Link Prediction)**: Implement Graph Attention Networks (GAT) to predict missing links and unobserved conspirators with probabilistic certainty scores.
3. **Multi-Modal Evidence Search**: Ingest CCTV imagery and wiretap audio using CLIP and Whisper embeddings for unified multi-modal suspect retrieval.

### 6.3 Inter-Agency Interoperability (National Law Enforcement)
1. **ICJS / CCTNS Integration Adapter**: Provide secure JSON/REST ingestion bridges to sync FIR records directly from state CCTNS police servers.
2. **NATGRID / FIU-IND Hawala Bridge**: Implement automated financial intelligence data connectors to ingest STR (Suspicious Transaction Reports) from the Financial Intelligence Unit.

### 6.4 Security & Air-Gapped Deployment
1. **Zero-Trust PKI & Hardware Security Modules (HSM)**: Cryptographically sign Section 65B Electronic Certificates using government-issued e-Sign PKI tokens.
2. **Air-Gapped Containerized Packaging**: Package the entire stack into a single offline Docker Compose bundle capable of running on isolated police tactical laptops without internet access.
